# 小登哥灵魂合盘 - 前端 H5 页面

纯静态 HTML 前端，通过 Nginx 提供 SPA 服务，反向代理后端 API。

## Docker 镜像

- **ACR**: `registry.cn-shanghai.aliyuncs.com/dewey_zodiac/zodiac-dewey-frontend:latest`

## 部署

```bash
docker pull registry.cn-shanghai.aliyuncs.com/dewey_zodiac/zodiac-dewey-frontend:latest
```

配合 `docker-compose.yml` 和后端服务一起使用。
